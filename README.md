# Apple electrocution-bootanimation
Apple electrocution bootanimation for google pixel

# Status
⚠️ In development !!!

Tested on a Google Pixel 9a running Android 17 with Magisk; it doesn't work at boot but works with the command 'bootanimation'.

# Installation
1. Install the zip form releases https://github.com/axy0n-qli/Apple-electrocution-bootanimation/releases
2. Open Magisk (or other root manager)
3. Go to Modules click on + and install from storage
4. Select your zip confirm installation and reboot
